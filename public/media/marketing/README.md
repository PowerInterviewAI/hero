# Marketing images

Nothing in this folder is a PLACEHOLDER card any more. The four hero posters are
real frames cut from the demo clips they front, and the avatar is a real default
avatar. Both are generated — don't hand-edit them, change the script and re-run.

**Keep the exact dimensions when you swap anything.** Each file is referenced
with explicit `width`/`height` (or is a `<video poster>` inside a fixed-ratio
frame), so a different aspect ratio will either letterbox or shift the layout.

## Hero carousel posters — 1920×1080 (16:9)

Referenced from `src/components/sections/hero/constants.ts`, and reused as the
`poster` for the two demo clips embedded in the docs — see the `VIDEO_POSTERS`
map in `src/lib/media.ts`.

These are the first paint of the hero, so they are the LCP element. They are
also what a viewer sees when autoplay is suppressed — which happens deliberately
under `prefers-reduced-motion` and Data Saver — so they have to carry the clip
on their own.

Regenerate with:

```bash
python scripts/generate-posters.py            # all four
python scripts/generate-posters.py coding-2   # just one, by path fragment
```

That script needs **ffmpeg** on PATH and **Pillow** (`pip install pillow`). It
is the only Python in the repo; it earns its place because the job is
frame-extraction plus compositing, and ffmpeg is an external tool either way.
It holds the chosen timestamp and the callout geometry for each poster.

| File | Frame | Annotated with |
|---|---|---|
| `poster-live-interview.jpg` | `live-interview-assistant.mp4` @ 90s | "Suggestions on your screen" on the laptop, "Invisible in the shared window" on the monitor |
| `poster-coding-1.jpg` | `coding-challenge-1.mp4` @ 42s | "Solution in the stealth overlay" |
| `poster-coding-2.jpg` | `coding-challenge-2.mp4` @ 30s | "Read the answer, keep typing" |
| `poster-coding-3.jpg` | `coding-challenge-3.mp4` @ 42s | "Scrolled with hotkeys alone" |

They are **JPEG, not PNG**. These are camera frames, and the poster is the LCP
element - the same image is ~4.7x lighter as q88 JPEG (200-290 KB) than as PNG
(1.0-1.35 MB), with no visible cost to the annotation text. Don't "restore" them
to PNG; `src/lib/media.ts` reads JPEG headers for intrinsic size just fine.

Each carries a topic chip top-left (GRAPH TRAVERSAL, CONNECTED COMPONENTS, …).
The three coding clips are shot from the same angle at the same desk and are
otherwise near-indistinguishable as stills — the chip is what tells them apart
in the carousel. The chip text deliberately does **not** repeat the clip title,
which the carousel already prints in the figcaption directly below the video.

> All four clips are 2560×1440, so the posters stay 16:9. The docs screenshots
> that were briefly used here (`media/docs/app-overview.jpg`) are 1482×1083 — a
> 1.37 ratio that letterboxes badly inside the 16:9 frame.

If you re-shoot a clip, the old timestamp will point at something else. Pick a
new one, put it in `POSTERS` in the script, and re-run — then actually look at
the output.

## Testimonial avatar — 96×96

`avatar-placeholder.png` — a neutral silhouette default avatar (dark disc, muted
figure, faint brand ring), generated by `node scripts/generate-placeholders.mjs
avatar`. Rendered at 36 px, so 96 covers 2×+.

It only appears if an entry in `src/config/testimonials.ts` sets `avatar`, and
that file ships empty on purpose (real quotes only). A real headshot is the only
correct replacement for a real person — keep this as the no-photo fallback
rather than dropping stock faces in.
